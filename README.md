# **SharpGrounds**

## General Information

This project is a C# (ASP.NET CORE MVC) port of our CSCI 40 semestral project that was made with the Django framework.

This is meant to act as practice and to familiarize ourselves with how ASP.NET Core MVC, CSS, HTML, and different JavaScript [framework/s] work(s), and hopefully, be able to make another project that will serve as a "portfolio repository" where we (the authors, and friends), may put information about us that we are comfortable sharing to others. We may also step foot and try out Java Spring Boot!

We will try our best to leave comments where possible so that we, and others who may stumble upon this project repository, may learn, and not be confused by whatever code they are seeing.

This project, once majority or all of it is done, will be deployed in Vercel for some time.

## Want to Contribute?

### Open to who?

We are open to contributions, only mainly from our friends or people we know though. We apologize if you wish to join and contribute with code. For our friends/people we know, please request permission from the main contributors to be included. Thank you!

#### **IMPORTANT**

Please refer as well to our [CONTRIBUTING](./CONTRIBUTING.md) file for some standards on how our code, commits, and comments are done or implemented.

### Still want to contribute but not a friend of ours, or knowledgable enough in programming?

Worry not! For code is not the only way you can contribute to us! Feel free to leave comments, suggestions, and bugs you may have found while trying or running our project! This also applies to our friends who contribute to our project via code.

Suggestions may include, but are not limited to:

1. Beautification side of the program (javascript, css).
2. Better implementation of certain parts of the project.
3. Ideas and literal suggestions regarding the framework and the associated parts of it.
4. Possible JavaScript frameworks (frontend and/or backend) that we can explore.

Any comment counts! As long as it is not very negative or an attack on anyone.

## Our stance/thoughts on Generative AI

While we are not super against the use Gen AI/LLMs, we hope to limit the use of them as this project serves as a learning experience to us, and our fellow developers. Feel free to leave comments and/or suggestions that you and your AI buddy(ies) have come up with.

If we do use any gen AI tools in this project, we will include/write them down in our comments, commits, and in this README file.
